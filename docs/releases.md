# Журнал викаток prod

Один рядок — одна викатка `npm run release` (`docs/RUNBOOK.md` §3). Рядок друкує сам реліз; «Результат» дописує той, хто пройшов чекліст RUNBOOK §4 (3.10.a–e).
Без персональних даних: ні `tg_id` (лише «збігається»), ні текстів записів, ні адрес пінгу, ні токенів — репозиторій публічний.
Bookmark — точка відкату БД до міграцій цього релізу (`RUNBOOK` §5); повні команди відкату — у `~/adhd-releases/<час>-<sha>/rollback.txt` на машині, з якої викочували.
