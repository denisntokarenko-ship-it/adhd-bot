# Специфікація — індекс

| Файл | Що всередині | Хто читає |
|---|---|---|
| `00-common.md` | стан проєкту, терміни, ролі, нефункціональні вимоги | **усі, завжди** |
| `phase-N.md` | зріз фази N: задача, історії P1/P2/P3 з Given/When/Then, поза межами, невідоме (з'являються з 0.2: `phase-0.md`, `phase-1.md`; далі — кроки N.0) | завдання й рев'ю Фази N |
| `decisions.md` | ухвалені рішення з причинами, append-only | хто сумнівається «чому так» |
| `open-questions.md` | невідоме, блокуючі вгорі | перед стартом фази, спека фази |

Правило: читаєш `00-common.md` + зріз своєї фази. Спеку цілком — ніколи.
Бюджет: кожен файл ≤ 40 КБ, тримає `bash scripts/check-docs.sh` (з 0.3 — `npm run check:docs` у CI). Переріс — ріжеться (`phase-6-shop.md`), а не читається вибірково.
