# Специфікація — індекс

| Файл | Що всередині | Хто читає |
|---|---|---|
| `00-common.md` | стан проєкту, терміни, ролі, нефункціональні вимоги | **усі, завжди** |
| `phase-N.md` | зріз фази N: задача, схема, історії P1/P2/P3 з Given/When/Then (id `S<фаза>.<n>`, критерії `<n>.<n>.<літера>`), поза межами, невідоме | завдання й рев'ю Фази N |
| `phase-0.md` | Фаза 0: Worker на вебхуку, preview/prod, `users`, `heartbeat`, `/start`, `/health`, cron + монітор, allowlist, CI | кроки 0.3–0.5, R-0 |
| `phase-1.md` | Фаза 1: схема `captures`/`items`/FTS/`ai_calls`/`points_ledger`, контракт розбору Haiku, дати й межі доби, квитанція, «не так», голос, пересилання, `/today`, `/export` | кроки 1.1–1.5, R-1 |
| `phase-2.md` | Фаза 2: `reminders`, планувальник, ескалація 5→15→30, відправка з cron, кнопки ✅ ⏰ 🗑 і очки, гонки, ліміт 6/год і зведення, події й дорога, «день + частина доби», тиша/пауза, варіації текстів | кроки 2.1–2.4, R-2 |
| `phase-2-dates-texts.md` | зріз Фази 2: дата «день + частина доби» (S2.8), `/pause` і `/resume` (S2.9.e–g), варіації текстів, `/quiet`, числівники з голосу — читати **разом** з `phase-2.md` | кроки 2.3–2.4, R-2 |
| `phase-3.md` | Фаза 3: принципи, константи, схема `0005`, огляди ранок / вечір / тиждень у черзі `reminders` (`digest_*`, S3.1–S3.6), межа доби й TTL огляду, «ранок забирає ранкові нагадування», поза межами, невідоме | кроки 3.1–3.3, R-3 |
| `phase-3-settings-prod.md` | зріз Фази 3: `/settings` і `/tz`, перенос коренів планувальника, зміна поясу, меню команд (S3.7–S3.9), перший prod і критерії «живе» (S3.10) — читати **разом** з `phase-3.md` | кроки 3.2–3.3, R-3 |
| `phase-4.md` | Фаза 4: `routines`, `routine_logs`, перебудова `reminders` (`0006`), майстер `/routines`, межа з ШІ (назва — не запис), слоти й ескалація ліків, «прийняв ✅» / «пропущу» / «+15 хв», `missed` мовчки, ранок і вечір з рутинами (S4.1–S4.9) | кроки 4.1–4.3, R-4 |
| `decisions.md` | ухвалені рішення з причинами, append-only | хто сумнівається «чому так» |
| `open-questions.md` | невідоме, блокуючі вгорі | перед стартом фази, спека фази |

Правило: читаєш `00-common.md` + зріз своєї фази. Спеку цілком — ніколи.
Бюджет: кожен файл ≤ 40 КБ, тримає `bash scripts/check-docs.sh` (з 0.3 — `npm run check:docs` у CI). Переріс — ріжеться (`phase-6-shop.md`), а не читається вибірково.
