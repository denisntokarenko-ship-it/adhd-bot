### S2.8 · P2 · Дата: «сьогодні ввечері», «завтра зранку» (крок 2.3)

Закриває **частину** боргу R-1 — частину доби. **Не закриває** живий дефект (його знайшов крок 1.4, `docs/notes/whisper-uk.md`; лишається в «Борг» `PROGRESS.md`): «у п'ятницю о 14:30», сказане в п'ятницю, і «дейлі на 9 ранку» без дня дають запис без дати й без питання — тож «нагадування немає, і ніхто не знає». Рішення про нього — окреме (R-2 або крок 2.3 за вказівкою диспетчера), не мовчки.

Рішення (критерій — не загубити намір людини й не слати пінг не в ту пору доби): **частина доби стає годиною**, а не `all_day`; тут ШІ лише парсить, код нічого не підміняє. **Години 09/13/19 підтвердив Денис (2026-11-20, «Так, 09/13/19»; `decisions.md`)**; перегляд після 2 тижнів — `open-questions.md`.

| Слова | Година (локальна) |
|---|---|
| вранці, зранку, уранці | 09:00 |
| вдень, у обід | 13:00 |
| ввечері, увечері | 19:00 |
| вночі, на ніч | дата неоднозначна (`date_unclear`) — як зараз |

- **2.8.a** Правило живе в системному промпті розбору (`src/ai/prompt.ts`): таблиця вище + «день без частини доби не вигадуй годину». Контракт відповіді не змінюється (нових полів нема).
- **2.8.b** Тести (мок Haiku відтворює відповідь за правилом; перевіряється промпт і шлях `due_local → due_at`): «завтра зранку» → завтра 09:00 за tz; «сьогодні ввечері» о 14:00 → сьогодні 19:00; «сьогодні зранку» о 14:00 → 09:00 уже минуло → без дати + питання «дата вже позаду» (S1.3).
- **2.8.c** Квитанція показує годину як звичайно; «Не так» виправляє.
- **2.8.d** Живий прогін на справжньому Haiku: «завтра зранку», «сьогодні ввечері», «у п'ятницю вдень»; результат у «Рішення» PROGRESS.md.

### S2.9 (продовження) · P2 · `/pause` і `/resume` (крок 2.4)

Режим тиші, `inQuietHours` і зведення — S2.9.a–d у `phase-2.md`.

- **2.9.e** Команда `/pause`: без аргументів — кнопки `1 год · 2 год · 4 год · до ранку` (`pz:<хв>`, «до ранку» = наступне `quiet_to`); `/pause N` (ціле 1–24 год) → `pause_until = now + N год`; `N` поза діапазоном або не число → дружня підказка без змін; нова пауза замінює стару. Відповідь: «Тиша до 16:00. Усе, що назбирається, прийде одним повідомленням» (пул ≥ 3).
- **2.9.f** `/resume` знімає паузу (`pause_until = NULL`); без активної паузи — «паузи й не було». Після `/resume` усе накопичене надсилається в найближчий тик — одним зведенням, якщо ≥ 2 запізнілих.
- **2.9.g** Пауза 2 год із трьома нагадуваннями всередині → 0 повідомлень під час паузи, 1 зведення після неї; тихі години + пауза поверх — діє довша.

### S2.10 · P2 · Варіації «друг з гумором» (крок 2.4)

- **2.10.a** Пули ≥ 5 варіантів: `due`, `repeat` (для спроб 2, 3, 4 — наростаюча наполегливість, але без вини), `eve_before`, `leave_now`; ≥ 3: заголовок зведення, відповіді ✅ ⏰ 🗑, відповіді `/pause`, `/resume`, відповіді на дорогу. «👍» на `eve_before` (2.4.l) — фіксований короткий текст, пулу не потребує.
- **2.10.b** Вибір не повторює попередній: для нагадувань — `variant_idx` попередньої відправки цього користувача того ж пулу (запит до `reminders`, не пам'ять isolate); для підтверджень — **колонка на пул** (НФ-4, як `greet_`/`today_variant_idx`): `users.ack_ok_idx`, `ack_later_idx`, `ack_rel_idx`, `ack_pause_idx`, `ack_resume_idx`, `ack_travel_idx`. Один спільний індекс давав би дослівний повтор: ✅ (idx 2) → ⏰ (idx 0 перезаписує) → ✅ знову бере 2. Тест: саме ця послідовність із детермінованим `rng`, який «хоче» повтор → два ✅ різні; і два нагадування поспіль того ж виду → різні тексти.
- **2.10.c** Заборонені слова (НФ-4) проходять по всіх нових пулах автоматично; до 2 емодзі, до 4 рядків; назва запису екранується; назва довша за 80 символів обрізається з `…`.

### S2.11 · P3 · `/quiet` (крок 2.4)

- **2.11.a** `/quiet` → два кроки кнопками: початок `22:00 · 23:00 · 00:00`, кінець `07:00 · 08:00 · 09:00`, плюс «без тихих годин» (`quiet_from = quiet_to`). Callback-и без стану (`qt:f:<хв>`, `qt:t:<від>:<до>`); відповідь називає вікно «23:00–08:00».
- **2.11.b** Зміна діє з наступного тика; уже зібрані `pending` не переписуються. Повне меню налаштувань — Фаза 3.2.

### S2.12 · P3 · Числівники з голосу (крок 2.4, не блокує)

Закриває борг 1.4 («п'ятнадцятого» → «5-го»).
- **2.12.a** У виклик Whisper додається `initial_prompt` — одне українське речення з порядковими числівниками. Друга лінія захисту — квитанція голосового вже показує розпізнане курсивом (S1.7).
- **2.12.b** Вимір (3 фрази × 2 прогони з підказкою й без; таблиця в `docs/notes/whisper-uk.md`): не покращує — прибрати й записати «не допомагає» в «Рішення». Мок-тест: виклик STT містить параметр, без нього працює як раніше.
