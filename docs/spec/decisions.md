# Рішення

Append-only: рядки лише дописуються. Скасоване рішення лишається з позначкою «Скасовано РРРР-ММ-ДД на користь …» — інакше наступна сесія переухвалює те саме.
Рішення плану (опитування 2026-11-20) — у таблиці «Ухвалені рішення» `docs/PLAN.md`; тут — рішення, ухвалені під час специфікації й реалізації.

Формат: `- **[РРРР-ММ-ДД] [рішення]** — [причина, одне речення].`

- **[2026-11-20] Специфікація ріжеться на зрізи `docs/spec/phase-N.md` + `00-common.md`, кожен ≤ 40 КБ** — сесія кроку читає лише свій зріз, бюджет тримає `scripts/check-docs.sh`.
- **[2026-11-20] Доступ лише за allowlist `ALLOWED_TG_IDS` (секрет), порожній список = відхилити всіх** — відкритий бот дозволив би чужим спалювати бюджет ШІ й плодити рядки; «схема під багатьох» не означає «двері відчинені» (`phase-0.md`, S0.6).
- **[2026-11-20] Пінг монітора — лише після успішного запису heartbeat у D1** — інакше cron, що вже не може писати, виглядав би живим; тиша = тривога.
- **[2026-11-20] `/health` — 200 навіть коли cron ще не запускався (`stale:true`), 503 лише при збої D1; `sha` приходить зі змінної деплою** — щойно викочений Worker чекає першого cron до ~15 хв, хибна тривога під час релізу гірша за прапорець.
- **[2026-11-20] Усі часові поля — з injectable `clock`, без SQL `DEFAULT` на час** — тести фіксують час (`setSystemTime`); прямих `Date.now()` поза `clock.ts` немає.
- **[2026-11-20] `users.plan` і `users.ai_consent_at`, `items.person_id` не створюються у Фазах 0–1** — додаються міграціями, коли потрібні; `person_id` посилався б на таблицю, якої ще немає.
- **[2026-11-20] Нова таблиця `captures` (одне вхідне повідомлення) поза `PLAN.md`** — дає ідемпотентність за `update_id` на рівні UNIQUE, «оренду» для повторів і точку відліку для «не так»; без неї очки й записи дублюються при повторі доставки Telegram.
- **[2026-11-20] Очко `capture` — за захоплення (повідомлення), не за запис; частковий унікальний індекс у БД** — не заохочує дроблення, повтор доставки не нараховує вдруге.
- **[2026-11-20] Схема відповіді Haiku має сьомий прапорець `date_unclear`** — без нього код не відрізнить «дати не було» від «дата була, але неоднозначна», а правило «неоднозначне → без дати + уточнення» не виконати. Це не поле «дії».
- **[2026-11-20] Відповідь ШІ валідується суворо: зайве поле, не той тип, невідомий `kind` — відхилення всієї відповіді й запасний шлях; довжини нормалізуються (обрізання), а не відхиляються** — доказ, що «полів-дій» немає, простіший, ніж їх чистка; довгий заголовок не варто втрачати розбір.
- **[2026-11-20] `due_local` — локальний ISO без зсуву; переведення в UTC лише кодом (`localToUtc`): неіснуючий час (літній перехід) зсувається вперед, подвійний — перше входження** — ШІ не знає зсувів; дві детерміновані точки дають тестовані межі.
- **[2026-11-20] «Минуле» = `due_at ≤ now`; для `all_day` — дата < сьогодні в `tz`; далі за 2 роки = неоднозначне** — запис не втрачається, дата не вгадується, людину питають однією короткою фразою.
- **[2026-11-20] «Не так» і повтор розбору замінюють записи (DELETE + INSERT в одному batch) — єдині дозволені видалення в Фазі 1** — це заміна власних записів захоплення за явним натисканням кнопки (правило 3 «видалення лише кнопками» збережене); запасна нотатка — службова.
- **[2026-11-20] Друге «Не так» бере оригінал + найновіше виправлення; вікно виправлення 10 хв** — зберігати ланцюг виправлень для MVP зайве, стан тримає `captures.fix_requested_at` без нових колонок у `users`.
- **[2026-11-20] Повтор розбору: 6 спроб із затримками 5 хв/15 хв/1 год/3 год/6 год, далі `gave_up` без повідомлень; у режимі тиші й при вичерпаному ліміті спроба не витрачається** — запис не губиться, а людина не отримує нічного шуму чи сорому.
- **[2026-11-20] Ім'я автора пересланого повідомлення не йде в ШІ й не зберігається** — мінімізація даних: потрібен лише текст.
- **[2026-11-20] Whisper-виклики не рахуються в `ai_calls` і денний ліміт Claude** — безкоштовна квота Workers AI, не бюджет Claude; їх не обліковують, доки не з'явиться плата.

- **[2026-11-20] `/export` — JSON `version:1` лише власних даних; `ai_calls` і `tg_id` не експортуються** — вихід із системи без прив'язки до Cloudflare; облік вартості й ідентифікатори людині не потрібні.
