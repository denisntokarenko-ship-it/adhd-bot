# Whisper на українській — заміри якості (крок 1.4, S1.7.g)

Модель `@cf/openai/whisper-large-v3-turbo` через біндинг Workers AI (`env.AI`), `language="uk"`, `vad_filter=true`.
Питання з `open-questions.md` (Фаза 1): лишаємо Whisper чи шукаємо інший STT. Припущення: придатні ≥ 16 з 20 без правок.

## Перевірено живцем (2026-11-20, `wrangler dev` з віддаленим AI)

Файл — справжній ogg/opus (контейнер Telegram-голосових), 16 кГц, фраза про лікаря й корм.

| Що перевірено | Результат |
|---|---|
| Вхід | `audio` — **base64-рядок** байтів ogg/opus як є (без конвертації); відповідь `{text, transcription_info, word_count, segments, vtt}` |
| `language: "uk"` | приймається; `transcription_info.language="uk"`. Без параметра модель визначила мову по-своєму (російська мова → `ru`) |
| Вплив `language="uk"` на суржик | російська фраза «и ещё» з `uk` → «і ще», з `ru` лишилась «и ещё»: примусова `uk` частково «українізує» російські слова. Для суржику це плюс (Claude отримає українське), для справжньої російської — спотворення |
| Тиша й білий шум (3 с) **без** VAD | `"Дякую за перегляд!"` — галюцинація; без захисту вона стала б фантомним записом |
| Тиша й шум **з** `vad_filter: true` | `text: ""`, `duration_after_vad: 0` → бот каже «не розчув». Мовлення з VAD розпізнається без втрат |
| Затримка | 0,5–3 с на 5 с аудіо |
| Ціна | документація: $0,000513 за хвилину аудіо — **не безкоштовно**, як припускала спека (1.7.f); при ≤ 20 голосових на день це копійки |

## Висновок

- **Підсумок.** Тиша й шум — 2/2 правильно (запису немає). З 17 фраз, які можна звірити (№12 вільна, не звіряється): ✅ 6, 🟡 8, ❌ 3 (№8, №15, №17). Зміст зрозумілий у 14 з 17 (82 %); «без правок» — лише 6 з 17 (разом з тишами 8 з 19). Припущення «≥ 16 з 20 без правок» за суворим критерієм **не виконується**; за критерієм «зміст зрозумілий» (14 + 2 тиші = 16 з 19) — виконується.
- **Що ламається.** (1) числівники: «п'ятнадцятого» → «5-го», і дата записується неправильно — тихий дефект, людина помітить лише прочитавши 🎙; (2) шепіт і фоновий шум дають сміття, а Claude **домислює** осмислений запис з уривка («Купайте подару» → «Купити подарунок»); (3) суржик і російські слова розпізнаються як є («встречі», «врач»), Claude їх нормалізує — це нормально.
- **Не вина STT (розбір, крок 1.2):** «завтра зранку…», «у п'ятницю о 14:30» у п'ятницю й «дейлі на 9 ранку» дають записи «без дати» без питання про дату; список «молоко, хліб, яйця, порошок» лишився однією задачею.
- **Рішення: Whisper large-v3-turbo лишаємо** для MVP, інший STT не шукаємо. Підстави: 82 % зрозумілих на суржику й шумі вулиці, помилки видно в квитанції (🎙 курсивом) і виправляються через «Не так», ціна — копійки. Перегляд — після 2 тижнів вжитку, якщо частка «Не так» після голосових висока.
- **Далі (не в 1.4):** (а) дату, отриману з числа голосу, підсвітити питанням у квитанції; (б) спробувати без `language` (автовизначення) на суржику; (в) для шепоту/шуму — мінімальна довжина тексту чи поріг `no_speech`; (г) правило промпту: з уривка не домислювати запис, а класти сирий текст у `note`.
