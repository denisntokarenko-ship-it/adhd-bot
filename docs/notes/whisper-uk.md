# Whisper на українській — заміри якості (крок 1.4, S1.7.g)

Модель `@cf/openai/whisper-large-v3-turbo` через біндинг Workers AI (`env.AI`), `language="uk"`, `vad_filter=true`.
Питання з `open-questions.md` (Фаза 1): лишаємо Whisper чи шукаємо інший STT. Припущення: придатні ≥ 16 з 20 без правок.

## Перевірено живцем (2026-11-20, `wrangler dev` з віддаленим AI)

Файл — справжній ogg/opus (контейнер Telegram-голосових), 16 кГц, фраза про лікаря й корм.

| Що перевірено | Результат |
|---|---|
| Вхід | `audio` — **base64-рядок** байтів ogg/opus як є (без конвертації); відповідь `{text, transcription_info, word_count, segments, vtt}` |
| `language: "uk"` | приймається; `transcription_info.language="uk"`. Без параметра модель визначила мову по-своєму (російська мова → `ru`) |
| Вплив `language="uk"` на суржик | російська фраза «и ещё» з `uk` → «і ще», з `ru` лишилась «и ещё»: примусова `uk` частково «українізує» російські слова. Для суржику це плюс (Claude отримає українське), для справжньої російської — спотворення |
| Тиша й білий шум (3 с) **без** VAD | `"Дякую за перегляд!"` — галюцинація; без захисту вона стала б фантомним записом |
| Тиша й шум **з** `vad_filter: true` | `text: ""`, `duration_after_vad: 0` → бот каже «не розчув». Мовлення з VAD розпізнається без втрат |
| Затримка | 0,5–3 с на 5 с аудіо |
| Ціна | документація: $0,000513 за хвилину аудіо — **не безкоштовно**, як припускала спека (1.7.f); при ≤ 20 голосових на день це копійки |

## 👤 Інструкція для Дениса: 20 голосових preview-боту

Бот — preview (той самий чат, де ти тестував 1.3). Кожну фразу — **окремим голосовим** повідомленням (утримуй мікрофон), не пересилай готові.
Текст зі стовпця «Що сказати» — орієнтир: **кажи своїми словами й так, як говориш насправді**, але запиши (хоч коротко), що саме сказав, якщо відійшов від фрази.
Після кожного дивись, що бот відповів: 🎙 курсивом — це те, що він розпізнав. «Не так» не тисни — вимірюємо перший результат.
Закінчиш — напиши мені «готово»: я сам візьму розпізнане й розкладене з бази preview, ти нічого не переписуєш.
